04 / A CLOSER LOOK

실제 문장에서는 어떻게 달랐을까

영어 원문 · 한국어 번역 병기 / 시드 17 · 각 유형에서 처음 8개

한국어는 읽기를 돕는 번역입니다. 모델은 영어 원문으로 학습·예측했으며, 정답은 번역 해석에 맞춰 바꾸지 않고 원자료 라벨을 유지했습니다. 평가 대상은 입력으로 주어지며, 사례만으로 Attention의 판단 원인을 설명할 수는 없습니다.

어떤 데이터와 모델을 사용했나요?

MAMS-ATSA 공식 분할: 학습 4,297문장·11,186사례, 검증 500문장·1,332사례, 테스트 500문장·1,336사례. 두 모델 모두 단방향 1층 LSTM(은닉 64), 고정 GloVe 100차원, 동일한 평가 대상 벡터와 위치 표식을 사용했습니다. 이 과제는 문장 전체의 감정이 아니라, 주어진 대상의 부정·중립·긍정을 분류합니다.

두 모델의 비교 조건은 공정한가요?

같은 데이터, 공통층 초기값, 배치 순서와 학습 규칙을 적용했습니다. 최대 12 epoch, 검증 Macro-F1이 3회 연속 개선되지 않으면 종료했습니다. Attention에는 추가 학습 파라미터가 있어 모델 용량의 영향을 완전히 분리하지 못했습니다.

차이의 불확실성은 어느 정도인가요?

추가 학습과 해석에 주의할 점은?

세 번째 시드 83은 기존 테스트 결과를 본 뒤 동일 조건으로 추가한 반복입니다. 새로운 맹검 검증이 아닙니다. 시드 세 개와 고정된 분할 하나의 제한된 실험이며, 최적 수렴을 보장하지 않습니다. Attention 가중치가 큰 표현을 곧바로 판단의 원인으로 해석해서도 안 됩니다.
