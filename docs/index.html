비율의 기준각 칸의 비율은 해당 모델의 전체 오답 중 차지하는 비율입니다. 평균 풀링은 1,395회, Attention은 1,049회가 기준이며, 각 행을 100%로 계산한 값은 아닙니다. 대각선은 정답이라 제외했습니다.

평균 풀링의 특징

긍정을 중립으로 판단한 경우가 26.3% (367회)로 가장 많았습니다. 긍정과 중립을 서로 혼동한 경우는 전체 오답의 약 48.5%였습니다.

Attention의 특징

긍정을 중립으로 판단한 경우가 24.7% (259회)로 가장 많았습니다. 평균 풀링보다 전체 오답이 346회 적었고, 긍정과 중립을 서로 혼동한 횟수도 줄었습니다.

긍정을 맞힌 비율에서 차이가 컸습니다.

실제 긍정인 대상 중 맞힌 비율인 재현율은 평균 풀링 50.8%, Attention 63.7%였습니다. 이 값은 위 표의 ‘전체 오답 중 비율’과 계산 기준이 다릅니다. 두 모델 모두 긍정의 재현율이 세 감성 중 가장 낮았습니다.

같은 테스트 대상 1,336개를 시드 17·42·83으로 평가한 총 4,008회 예측을 모델별로 합산했습니다. 서로 다른 대상 4,008개를 평가한 것은 아닙니다. F1은 정답과 오답을 모두 포함한 전체 테스트 결과로 계산했습니다. 이 분석은 어디서 틀렸는지를 보여주며, 왜 틀렸는지까지 확인한 결과는 아닙니다.

05 / A CLOSER LOOK

실제 문장에서는 어떻게 달랐을까

영어 원문과 한국어 번역 / 시드 17의 결과에서 각 유형별 처음 8개

한국어 번역은 내용을 이해하기 위해 붙였습니다. 모델은 영어 원문을 보고 예측했습니다. ‘정답’은 원래 데이터셋에 표시된 값을 그대로 사용했으므로, 읽는 사람이 생각한 감성과 다를 수 있습니다. 분류할 대상은 모델에 미리 알려 주었습니다. 이 사례만으로 모델이 왜 그렇게 판단했는지까지 알 수는 없습니다.

어떤 데이터와 모델을 사용했나요?

MAMS-ATSA의 식당 리뷰를 사용했습니다. 학습 자료는 4,297문장(평가 대상 11,186개), 검증 자료는 500문장(1,332개), 테스트 자료는 500문장(1,336개)입니다. 한 문장에 여러 대상이 나올 수 있어 대상 수가 문장 수보다 많습니다. 예를 들어 “음식은 맛있지만 서비스는 별로다”에서 음식은 긍정, 서비스는 부정으로 분류합니다. 두 모델 모두 단어를 앞에서부터 읽는 1층 LSTM과, 단어를 숫자로 나타낸 GloVe 벡터를 사용했습니다. LSTM의 은닉 차원은 64, 단어 벡터는 100차원이며 단어 벡터는 학습 중 바꾸지 않았습니다. 두 모델에 같은 대상 정보와 문장 속 대상 위치를 알려 주었습니다.

두 모델의 비교 조건은 공정한가요?

두 모델에 같은 자료를 주고, 함께 사용하는 부분의 시작값과 자료를 학습하는 순서도 맞췄습니다. 최대 12 epoch까지 학습하되, 검증 Macro-F1이 3번 연속 좋아지지 않으면 멈췄습니다. 다만 Attention에는 추가로 학습하는 숫자값인 파라미터가 더 있습니다. 따라서 점수가 오른 이유를 Attention의 가중치 계산 방식만으로 설명할 수는 없습니다.

차이의 불확실성은 어느 정도인가요?

추가 학습 결과는 어떻게 해석해야 하나요?

시드 83의 학습은 앞선 테스트 결과를 본 뒤, 같은 조건에서 결과를 한 번 더 확인하려고 진행했습니다. 한 번도 보지 않은 새 테스트 자료로 검증한 것은 아닙니다. 난수 시드는 모델의 시작값 같은 무작위 요소를 정하는 번호입니다. 시드에 따라 점수가 달라질 수 있어 3개로 반복했지만, 이것만으로 결과가 충분히 안정적이라고 단정할 수는 없습니다. 학습 횟수도 제한했으므로 가장 좋은 성능에 도달했다고 말할 수는 없습니다. Attention에서 비중이 큰 단어가 나와도 그 단어 때문에 판단했다고 바로 결론 내리면 안 됩니다.
